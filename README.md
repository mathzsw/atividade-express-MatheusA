# Atividade Express + Handlebars

Aplicação desenvolvida com Node.js, Express e Handlebars.
O projeto foi enviado para a branch `master` em vez de `main`, pois ocorreram conflitos com a branch principal já existente no repositório durante o push no GitHub.

## Tema

Lista de Jogos 🎮

## Funcionalidades

- Listar jogos
- Cadastrar jogos
- Interface estilizada
- Uso de rotas GET e POST
- Uso do Handlebars

## Tecnologias utilizadas

- Node.js
- Express
- Express-Handlebars

## Como executar

Instalar dependências:

```bash
npm install
```

Executar projeto:

```bash
node app.js
```

Abrir no navegador:

```txt
http://localhost:3000
```
